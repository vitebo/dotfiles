# Git

- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org):
  `type(scope): description`, imperative and lowercase, no trailing period.
  Common types: `feat`, `fix`, `refactor`, `docs`, `chore`, `test`.
- One logical change per commit; don't mix refactors with behavior changes.
- Only commit when asked, or when the project's instructions allow it.
- Never push, force-push or rewrite published history without asking.
