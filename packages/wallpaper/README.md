# wallpaper

Desktop wallpaper matching the Catppuccin theme: misty mountain layers in Catppuccin
Mocha (5120x2880). The same image in light and dark mode.

- `~/Pictures/Wallpapers/catppuccin-mountains.jpg` -> `config/catppuccin-mountains.jpg`.

Setup (by hand, once per machine): System Settings → Wallpaper → Add Photo… (or
the `+` button) → `~/Pictures/Wallpapers/catppuccin-mountains.jpg`. Repeat for each
display if they don't share the wallpaper.
