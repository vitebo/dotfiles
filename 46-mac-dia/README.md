# 46-mac-dia

Installs [Dia](https://www.diabrowser.com) (`thebrowsercompany-dia` cask,
auto-updates), the web browser from The Browser Company. mac only: it's a GUI app.

## Default browser

macOS asks for confirmation before changing the default browser, so it's set by
hand, once per machine (installers don't change system preferences):

System Settings → Desktop & Dock → Default web browser → Dia
(or Dia's own "set as default browser" prompt on first launch).

Accounts, profiles and settings are synced by Dia itself, nothing versioned.
