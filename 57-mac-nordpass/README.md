# 57-mac-nordpass

Installs [NordPass](https://nordpass.com) (`nordpass` cask, auto-updates), a
password manager. mac only: it's a GUI app. Login is per machine, nothing
versioned.

Browser autofill comes from NordPass' Chrome extension, installed by hand from the
Chrome Web Store, like other extensions (see [46-mac-google-chrome](../46-mac-google-chrome)).
