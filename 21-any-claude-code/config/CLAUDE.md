# Personal instructions

Apply to every project, on every machine (personal and work).

## Communication

- Talk to me in Brazilian Portuguese. Write code, comments, docs and commit
  messages in English, unless the project says otherwise.
- Be direct: lead with the answer or the result, keep summaries short.

## Working style

- Start simple: the smallest change that solves the problem, no speculative
  abstractions or features nobody asked for.
- Follow the project's existing conventions (naming, structure, comment density)
  over my general preferences.
- Ask before adding dependencies or doing anything hard to reverse (deleting
  files, rewriting history, pushing).
- Verify changes by running them (tests, the script, the app) and say plainly
  what was and wasn't verified.
